# Convenciones del proyecto

## Comentarios en el código

- Todos los comentarios de código (`src/`, `tests/`) van **en español**, registro neutro/profesional (sin jerga regional).
- Todo archivo debe tener un comentario de cabecera breve explicando **qué hace ese archivo**, aunque no tenga más comentarios adentro.
- Esto aplica a partir de ahora para código nuevo y para el código existente (ya traducido).
- No aplica a: identificadores (nombres de variables/funciones/clases), strings de la API (mensajes de error, códigos como `VALIDATION_ERROR`), ni a la documentación de OpenSpec (`openspec/`), que siguen en inglés salvo pedido explícito.
